# IRON IQ — V1 Prototype

Commercial workout-app prototype built with Expo + React Native + TypeScript.

## Run it

1. Install Node.js LTS.
2. In a terminal, open this folder.
3. Run `npm install`
4. Run `npx expo start`
5. Open with Expo Go on a phone, or press `w` for web.

## Current prototype

- IRON IQ dark visual system
- Goal onboarding
- Dashboard
- Live workout logging mock
- Progress dashboard
- Sample AI coach recommendations
